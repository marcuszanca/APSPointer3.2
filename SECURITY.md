# Security Policy

## Public demo

Este repositório contém apenas uma demonstração estática com dados fictícios. Ele não deve conter segredos, credenciais ou dados internos.

Se você identificar acidentalmente qualquer informação que pareça sensível, abra uma issue sem reproduzir o dado sensível ou entre em contato com o mantenedor por um canal privado disponível no perfil do projeto.

## Recomendações para forks

- Não substitua os dados simulados por informações de produção em repositórios públicos.
- Não versionar senhas, tokens, chaves de API ou credenciais.
- Para exemplos de IP, prefira blocos reservados para documentação.
